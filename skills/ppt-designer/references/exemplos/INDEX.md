# Catálogo de referência de slides

1647 páginas de 22 decks e 980 peças, nas cores originais. Copie a técnica, nunca o conteúdo.

## Como usar

1. Sabe o que precisa desenhar: abra a lista do tipo em `por-tipo/`. As imagens estão em `tipo/<tipo>/`, com `★` primeiro.
2. Precisa decidir a grade do slide: abra `por-formato/` (1q, 2q, 3q, 4q).
3. Quadrante recortado perde a ligação com os vizinhos: abra `slide_origem` para ver como os painéis se encadeiam.
4. Para filtrar por deck, nota ou página, use `catalogo.json`. `quadrantes_conferido` indica se a contagem foi conferida no corte.
